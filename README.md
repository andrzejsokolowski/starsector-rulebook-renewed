# Rule Book - Renewed

Rules for one Starsector campaign. Negative rules make the game harder and give points; positive rules make
it easier and cost points. Every rule has its own level.

- **Opening it**: the Rule Book opens a few seconds after a new game starts (LunaLib setting). Open it again
  from the **Rule Book** entry on the intel screen.
- **Picking**: left click picks a rule, then raises its level. Right click lowers it. A negative rule and its
  positive mirror are never on together: picking one greys out the other. Nothing changes until you press
  **Confirm**.
- **Point budget**: with the LunaLib setting "Point budget" on (the default), you cannot confirm a set that
  costs more points than it gives.
- **Challenges**: a challenge names negative rules to keep on and a goal. Progress counts whenever those
  rules are on at the listed levels; there is nothing to start. "Enable required rules" in the Challenges
  tab switches on exactly the rules a challenge needs. Finishing one unlocks a reward rule for every
  campaign.
- **Achievements**: some rules are unlocked by achievements, kept by the mod Achievements - Renewed. A locked
  rule shows as **[ ? ]**; point at it to see what unlocks it. The LunaLib setting "Every rule unlocked"
  opens all rules without touching the real unlocks.
- **New Game Plus - Renewed**: the Rule Book writes a career point multiplier that New Game Plus - Renewed
  reads. Each point of budget left over adds 1 percent, each point over budget takes 1 percent away.

Requires LunaLib and Achievements - Renewed.

## Adding rules and challenges

One row per rule in `data/config/rulebook/rules.csv` and one row per challenge in
`data/config/rulebook/challenges.csv` (other mods can add rows to the same paths). The rule `type` is
`positive` or `negative`; a rule with 0 points is free. The `effect` column names a class implementing
`rulebookrenewed.rules.RuleEffect`. Rules with the same `pair` are mirrors: only one of them can be on. A
rule with `challenge:<id>` in its `unlock` column is the reward of that challenge, and `feat:<id>` names the
achievement `rbr_<id>`. `requiredMod` may name several mods with `|` between them; one of them must be
enabled.

New Game Plus - Renewed reads one sector memory key: `$rbr_ngpMultiplier`, the career point multiplier.
